Cadangan & pemulihan

Data disimpan di browser perangkat ini. Ekspor cadangan berkala agar tidak hilang saat data browser dihapus.

Kelola akun

Tambah profil keluarga, atur PIN masing-masing, dan wajib masukkan PIN saat berpindah ke akun yang dikunci.

Privasi

DompetKu versi ini bekerja secara lokal tanpa akun dan tanpa mengirim data ke server. Jangan masukkan PIN, kata sandi, atau informasi rekening rahasia.

Mode lokal

Aplikasi berusaha memakai IndexedDB, lalu localStorage sebagai cadangan. Setiap profil memiliki ruang data terpisah di penyimpanan browser pada perangkat ini. Ini bukan database server online; data dapat hilang jika data situs dihapus.
